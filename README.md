# CPPong
Implementation of the classic "Pong" videogame in C++, using [raylib](www.raylib.com).

![alt text](https://i.imgur.com/FHZJUj9.png "CPPong screen")

### Playing on your browser
You can play the game directly on your browser by visiting the [game page](https://rochoso.itch.io/cppong) on itch.io!

### Building with CMake
You need CMake installed to build this game. At the root of the game folder, build it with
```
cmake -S . -B build
```
### Compiling and running
After built, the game can be compiled with the command
```
cmake --build build
```
And then run with
```
./build/CPPong
```
